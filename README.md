# Manufacturing Analytics (PySpark ETL + ML Prototype)

## 🚀 Overview
This project is a **prototype ETL pipeline** for manufacturing data (CAD parts, production logs, quality inspections, maintenance).  
It demonstrates **Bronze–Silver–Gold data lake pattern**, **PySpark cleaning & feature engineering**, and **Spark ML regression** for part cost prediction.  
A simple **FastAPI backend** + **Streamlit dashboard** provide an interface for running jobs and visualizing KPIs.
